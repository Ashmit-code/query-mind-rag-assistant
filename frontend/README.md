# Frontend Application

Developer-tool UI for the RAG-Based Coding Assistant, built with React, Vite, and Tailwind CSS following `DESIGN.md`.

## Features
- Clean developer-tool aesthetic (dark-mode-first, Linear/Vercel inspired).
- Dual/Hybrid retrieval mode switcher (TF-IDF / Semantic / Hybrid).
- Structured response presentation: Explanation, Syntax, Code Snippet, Example Output, Complexity, Sources.
- Syntax highlighting and one-click copy.
